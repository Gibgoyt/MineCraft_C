# Sound attribution

Every sound in this tree is cut from a recording below, and each sound's own `README.md` names its file and what was done to it. Each pack's page on OpenGameArt states CC0, read on 2026-11-05, and so do the two packs' own text files noted here. CC0 asks for no credit; it's given anyway. **No Minecraft sounds are used.**
