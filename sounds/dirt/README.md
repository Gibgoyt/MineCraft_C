# sounds/dirt

A step in mud and a shovel moving dirt, with crunch impacts, low-passed, for a break. No pack has a recording called dirt, so this family is the one most worth listening to. Each sound's own `README.md` names its file and what was done to it.

`sounds/README.md` says how to change one. Which blocks use this family: `sound:` in `config/blocks/`.
